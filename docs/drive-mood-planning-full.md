# Drive Mood 기획서 (전체 버전)

## 1. 앱 한 줄 소개
운전 패턴을 리듬으로 읽고, 데이터에서 나온 짧은 문장으로 공감하며, 필요할 때 호흡으로 리듬을 맞춰주는 인카 동반자

## 2. 기획 배경
장시간 운전 시 피로와 긴장으로 운전 리듬이 흐트러지지만, 운전자는 이를 스스로 인지하기 어렵다. 기존 인카 앱은 일반적인 알림이나 콘텐츠 재생에 그쳐, 운전자의 실제 운전 패턴을 해석하고 공감하는 경험이 부족하다.

## 3. 핵심 기능

### 3.1 운전 리듬
조향각과 브레이크 패턴을 리듬으로 해석하여 시각화한다.
- 안정: 부드러운 파동 (파란)
- 불안정: 불규칙 파동 (주황)

### 3.2 마이크로 스토리
데이터 조건 조합으로 생성되는 짧은 공감 문장
예: "오늘따라 손이 편한 하루네요.", "어두운 길에서 손이 조금 긴장했어요."

### 3.3 숨 고르기 가이드
불안정 리듬 감지 시 30초 호흡 가이드와 리듬 동기화 연출

### 3.4 도착 리포트
오늘의 리듬 요약과 마무리 문장

## 4. 사용 시나리오
장거리 운전 중 리듬 불안정 감지 → 숨 고르기 제안 → 동기화 → 안정화 → 도착 리포트

## 5. 사용 API
- getCurrentSteeringWheelAngle
- getCurrentBrakePedalStatus
- getTripCurrentDrivingTime
- getRouteStateInfo
- getHvacTemperatureCurrent, getAmbientLightBrightness 등

## 6. 차별점
단순 웰니스 앱이 아니라 운전 리듬을 읽고 맞춰주는 경험

## 7. 개발 계획
4주 일정으로 프로토타입 구현 가능
