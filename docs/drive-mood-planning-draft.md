# Drive Mood 기획서 (초안 · 참고용)

> 현대자동차그룹 차량용 앱 개발 공모전
> 작성일: 2026-10-27
> 문서 상태: 초안 보관용

기준 문서는 [Drive Mood 기획서 — 전체 버전](drive-mood-planning-full.md)이다. 이 초안의 상세 내용은 기준 문서에 통합했으며, 이후 기획 변경은 전체 버전에 반영한다.

## 1. 앱 한 줄 소개
운전 패턴을 리듬으로 읽고, 데이터에서 나온 짧은 문장으로 공감하며, 필요할 때 호흡으로 리듬을 맞춰주는 인카 동반자

## 2. 기획 배경
장시간 운전 시 피로와 긴장으로 운전 리듬이 흐트러지지만, 운전자는 이를 스스로 인지하기 어렵다. 기존 인카 앱은 일반적인 알림이나 콘텐츠 재생에 그쳐, 운전자의 실제 운전 패턴을 해석하고 공감하는 경험이 부족하다. 차량이 이미 보유한 조향각·브레이크·운전 시간·경로 데이터만으로도 개인화된 케어가 가능하다.

## 3. 앱 주요 기능 및 차량 특화 요소

### 3.1 운전 리듬 시각화
조향각(`getCurrentSteeringWheelAngle`)과 브레이크 패턴을 리듬으로 해석하여 화면 하단에 파동으로 표현한다.
- 안정 운전: 작은 폭의 조향 보정이 일정한 주기로 나타남 → 부드러운 파란 파동
- 피로·긴장: 주기가 불규칙해지거나 진폭이 커짐 → 불규칙 주황 파동

### 3.2 마이크로 스토리
데이터 조건(운전 시간, 리듬 상태, 시간대, 경로, 좌석 점유)를 조합해 생성되는 짧은 공감 문장.
예시: “오늘따라 손이 편한 하루네요.”, “어두운 길에서 손이 조금 긴장했어요.”

### 3.3 숨 고르기 가이드
장시간 운전 + 불안정 리듬 감지 시 “지금 리듬이 흐트러졌어요. 호흡으로 다시 맞춰볼까요?”를 제안하고, 30초 호흡 가이드와 함께 운전 리듬 파동과 호흡 리듬이 동기화되는 연출을 보여준다. 동시에 현재 공조·앰비언트 상태와 제안 상태를 나란히 표시한다.

### 3.4 도착 리포트
도착 시 “중간중간 리듬이 흔들렸지만, 잘 도착하셨어요”라는 마이크로 스토리와 오늘의 리듬 요약을 제공한다.

**차량 특화 요소**: 조향각, 브레이크, 운전 시간, 경로, 공조·라이트 상태를 복합 활용. 외부 앱으로는 불가능한 실시간 차량 데이터 기반 경험.

## 4. 주요 사용 시나리오
장거리 운전 중(예: 서울→부산), 92분 경과 후 조향 패턴이 불안정해지면 화면 하단 파동이 불규칙해진다. “조금 긴장한 손이었어요. 지금 리듬이 흐트러졌어요. 호흡으로 다시 맞춰볼까요?”라는 메시지와 함께 30초 호흡 가이드가 나타난다. 운전자가 수락하면 호흡 원형 애니메이션과 운전 리듬 파동이 겹쳐지며 동기화되는 연출이 진행되고, 동시에 따뜻한 라이트 제안이 표시된다. 30초 후 “리듬이 조금 안정됐어요”와 함께 파동이 부드러워진다. 도착 시 오늘의 리듬 요약이 제공된다.

## 5. 개발 계획
현재 사용 가능한 Vehicle State(CAR_DRIVE, CAR_CLIMATE, CAR_LIGHTS, CAR_SEATS)와 NaviHelper API만으로 구현한다.
- 1주: SDK 연동 및 데이터 수집 (조향각 버퍼, 운전 시간, 경로)
- 2주: 리듬 점수 계산 + 마이크로 스토리 생성 로직
- 3주: UI (파동 시각화, 호흡 가이드, 현재 vs 제안 대비)
- 4주: 테스트 및 데모 영상

향후 TTS·Vehicle Control API가 열리면 음성 안내와 공조·라이트 자동 적용으로 확장한다.

## 6. 기대효과 및 발전 가능성
장거리·통근 운전자에게 운전 패턴을 리듬으로 해석하고 짧게 케어하는 새로운 경험을 제공한다. 전 차종에 적용 가능하며, 외부 앱으로 구현하기 어려운 차량 데이터 복합 활용이 강점이다. 향후 Control API 연동 시 제안된 분위기를 자동 적용할 수 있고, 사용자 패턴 학습과 가족 케어로 확장 가능하다.
