## 2. 문제 정의

- 장시간 운전 시 피로와 긴장으로 운전 리듬이 흐트러지지만, 운전자는 이를 인지하기 어렵다.
- 기존 앱은 일반적인 알림이나 콘텐츠에 그쳐, 운전 자체를 해석하고 공감하지 않는다.
- 운전자는 “내 운전을 알아주는” 느낌이 부족하다.

---

## 3. 핵심 콘셉트: 운전 리듬

Drive Mood는 조향각·브레이크 패턴을 **운전 리듬**으로 해석합니다.

- **안정적 리듬**: 부드러운 파동 → 편안한 운전
- **불안정 리듬**: 불규칙한 파동 → 긴장·피로 신호
- **숨 고르기**: 호흡 리듬과 운전 리듬을 맞춰 다시 안정화

동시에, 데이터 조합으로 생성되는 **마이크로 스토리**(짧은 한 문장)로 공감합니다.

| 구간 | 경험 |
|------|------|
| 평상시 | 운전 리듬 시각화 + 마이크로 스토리 |
| 리듬 불안정 | “리듬이 흐트러졌어요” + 숨 고르기로 맞추기 |
| 도착 | 오늘의 리듬 요약 + 마무리 문장 |
