## Figma 화면 구성 상세

### 1. 출발 화면
- 상단: 앱 이름 "Drive Mood"
- 중앙: “오늘 출발했어요. 리듬을 함께 지켜볼게요.”
- 하단: 부드러운 파랑 파동 (SVG 선)

### 2. 불안정 감지 화면
- 중앙: 메시지 카드 (“조금 긴장한 손이었어요.”)
- 하단: 불규칙한 주황 파동
- 색상 전환: 파란 → 주황

### 3. 숨 고르기 화면
- 중앙: 큰 호흡 원형 (“3초 들이쉬기 / 내쉬기”)
- 하단: 운전 리듬 파동과 호흡 리듬이 겹쳐지며 동기화되는 연출
- 오른쪽: 현재 vs 제안 라이트 상태 대비

### 4. 안정화 화면
- 파동이 다시 부드러워짐
- 메시지: “리듬이 조금 안정됐어요”

### 5. 도착 리포트 화면
- 요약 카드: 운전 시간, 리듬 안정도
- 마무리 문장: “중간중간 리듬이 흔들렸지만, 잘 도착하셨어요.”

## 나레이션 대본

Drive Mood는 운전 패턴을 리듬으로 읽습니다.
92분째, 조향 패턴이 불규칙해집니다.
운전자가 수락하면 호흡과 운전 리듬이 맞춰지는 과정을 보여줍니다.
도착 후에는 오늘의 리듬을 요약합니다.
