앱 내 ‘여정 시연’을 실제 버튼으로 시작해 일정 리듬·변화·주차·호흡·다음 주행·도착 리포트·기록 저장을 녹화했다. 동작 확인은 `instrumentation.txt`, 장면 시각은 `scenes.json`에 남아 있다. 사용자 기록을 합성 UI로 대체하지 않았다. 시연으로 생성한 기록은 앱에서 시연 기록으로 구분한다.

편집본은 시스템 바·계기판을 제외한 앱 창을 사용하고, 일부 대기 구간을 잘라 설명 자막과 원본 벡터 타이틀을 추가했다. 모든 채택 장면은 정상 속도이며 30초 호흡 구간은 약 30.3초를 연속으로 포함한다. 주행 중 리듬 그림에는 12초 주기의 작은 움직임이 있으며 센서 측정값을 표현하는 파형 그래프가 아니다. ‘시연 데이터’ 출처 표시를 유지하고 자동 공조·조명 제어, 호흡에 의한 점수 개선을 주장하지 않는다. 원본과 편집본의 장면 대응은 `artifacts/video/timeline.json`에 있다.

0.4.4는 세이지색 목적지 카드와 큰 남은 시간, 거리·도착 예상 시각, 다음 안내를 함께 표시한다. 도착 예상 시각은 기기 현재 시각에 내비의 남은 초를 더한 추정값이다.

다시 만들 때는 메인 APK와 androidTest APK를 설치한 뒤 실행한다. 녹화 도구는 기존 기록 서비스가 실행 중이면 시작하지 않는다.

```bash
python3 scripts/record-demo.py --output .tools/video-recordings/new-take
python3 scripts/render-demo.py --recording .tools/video-recordings/new-take --output artifacts/video
```

편집에는 Android Studio에 포함된 FFmpeg와 시스템의 librsvg를 사용한다. 렌더링 중간 파일은 `.tools/video-edits/`에 저장한다. 심사용 영상에는 참가자 실명·계정·SDK 키를 넣지 않았다.

## 에뮬레이터 준비

실제 차량 상태를 P·정지로 두고 앱을 연다. 왼쪽 `시연 → 여정 시연`을 누르고 필요한 차량 속도·알림 권한을 허용한다. 시연 배지는 모든 가상 값의 출처를 나타낸다.

## 전체 여정 (약 2분)

| 구간 | 화면과 행동 | 전달할 내용 |
| --- | --- | --- |
| 시작~14초 | 큰 ‘일정한 리듬’ 상태·짧은 문장과 하늘색 리듬 일러스트 | 차량의 조향과 브레이크가 경험의 출발점 |
| 14~34초 | 변화 관찰이 누적되면 살구색 ‘리듬 변화’와 잔잔한 일러스트·쉬어가기 제안 | 순간 회전이나 임의의 타이머로 피로를 단정하지 않음 |
| 주차 이후 | `30초 숨 고르기` 선택 | 3초 들숨·3초 날숨 5회, 실제 파형과 안내 파형 구분 |
| 호흡 중 | 현재 실내 24°C·조명 80%와 22°C·따뜻한 빛 30% 제안 비교 | 제안만 제공하며 설정을 자동 변경하지 않음 |
| 호흡 완료 | “나에게 건넨, 짧은 쉼” | 호흡 완료를 리듬 개선 결과로 바꾸지 않음 |
| 다음 주행 (80초 이후) | 전체 여정에서 일정한 신호로 돌아오거나 `안정 리듬` 장면을 선택 | 새 차량 신호가 일정할 때만 리듬 갱신 |
| 도착 | 기록을 마치거나 전체 여정의 도착 이벤트 대기 | 분석 구간·주행 시간·호흡 기록·리듬 변화가 저장됨 |

시연은 D에서 큰 상태와 짧은 문장만 있는 주행 화면으로 바뀐다. 상단 `시연 장면`에서 장면을 바꿀 수 있으며, 실제 차량은 계속 주차되어 있어야 한다. 전체 여정은 34~80초에 주차 상태로 바뀌므로 이때 30초 호흡을 시작한다. 80초부터 새로운 일정한 주행 데이터를 관찰하고 약 110초에 다시 주차하며 도착 이벤트가 발생한다. 수동 장면 선택 후에는 `전체 여정`으로 돌아가거나, 주차 장면에서 `기록 마치기`를 누른다.

## 별도 확인 장면

- `회전 구간`: 리듬 점수 산출을 잠시 제외한다.
- `연결 끊김`: 데이터 확인 상태와 파형 공백을 보여준다.
- `주차·숨 고르기`: 실제 차량 P 상태에서 호흡 안내를 연다.
- 왼쪽 `기록`: 시연 리포트를 다시 열고 주간 합계에서는 제외되는지 확인한다.
- 실제 가상 콘솔에서 D로 전환하면 앱은 조작을 제한하며, 진행 중이던 시연은 중단 기록으로 저장된다.

30초 동안 나만의 호흡을 따라가고, 쉬어갈 때의 실내 분위기를 제안받습니다.
도착한 뒤에는 관찰한 구간과 함께 오늘의 리듬을 남깁니다.
